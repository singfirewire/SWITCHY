# SWITCHY — RoIP (Radio over IP) Gateway

เชื่อม "วิทยุสื่อสารจริง (Walkie-Talkie)" เข้ากับ "ห้อง Intercom บน IP" ให้คนที่ถือมือถือพูดกับคนที่ถือวิทยุได้

```
                         Mini PC
  ┌───────────────────────────────────────────────────────────┐
  │  audioengine.Relay  (UDP :50500)                          │
  │        │                                                  │
  │        ├─► roip.Controller ── USB-Serial (RTS/DTR) ──┐    │
  │        │     (คีย์ PTT เมื่อมีคนพูด / VOX ในตัว)       │    │
  │        └─► roip.Gateway ── UDP ──► helper ── USB Soundcard │
  │                                       (Audio in/out)  │    │
  └───────────────────────────────────────────────────────┼───┘
                                                          │
                                    ┌─────────────────────┴────────────┐
                                    │   สายเคเบิลเข้าไมค์/หูฟังวิทยุ     │
                                    └──────────────────────────────────┘
```

มีสองส่วนที่แยกกัน (ต่อใช้ตัวใดตัวเดียวก็ได้):

| ส่วน | ใช้ทำอะไร | ต้องการฮาร์ดแวร์ |
|---|---|---|
| **PTT (คีย์วิทยุ)** | สั่งกดคีย์ส่งวิทยุจากแอป | USB-Serial CH340/FTDI + สายต่อขา PTT ของวิทยุ |
| **Audio bridge** | ส่งเสียงเข้า/ออกวิทยุ | USB Soundcard + สายเข้าไมค์/ออกหูฟังวิทยุ |

## 1. PTT ผ่าน USB-Serial (พร้อมใช้แล้วในเฟสนี้)

ตั้งค่าใน `config.json`:

```json
"roip": {
  "enabled": true,
  "serialPort": "COM3",
  "baud": 9600,
  "pttMode": "rts",
  "invertPtt": false,
  "voxThreshold": 0.02,
  "talkTailMs": 250
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `pttMode` | `rts` (ขา RTS) / `dtr` (ขา DTR) / `none` (ไม่คีย์ด้วยสาย — ใช้วิทยุโหมด VOX) |
| `invertPtt` | true = active-low (บอร์ด relay ส่วนใหญ่เป็นแบบนี้) |
| `talkTailMs` | หน่วงปล่อยคีย์หลังหยุดพูด — กันท้ายคำขาด (วิทยุจริงมักต้องการ 200–400 ms) |
| `voxThreshold` | (เฟส 2) ระดับเสียงที่ถือว่า "เริ่มพูด" เมื่อใช้ VOX แทนการกดปุ่ม |

**การต่อสาย (ตัวอย่างบอร์ด CH340 + รีเลย์/ออปโต):**

```
CH340 RTS ──► ตัวต้านทาน 1k ──► ฐานทรานซิสเตอร์ ──► ขา PTT ของวิทยุ (มักต่อกับ GND ผ่านสวิตช์)
GND      ──► GND ของวิทยุ
```

> ⚠️ ตรวจแรงดันของวิทยุก่อนต่อ — หลายรุ่นใช้ 3.3 V และขั้ว PTT อาจอยู่ในสายไมค์
> ใช้มิเตอร์วัดก่อน ไม่ควรเดา (ถ้าผิดอาจทำให้วิทยุเสียหาย)

**ทดสอบ PTT โดยไม่ต้องมีแอป:**
```bash
# เปิดเซิร์ฟเวอร์ แล้วยิง Tally/PTT จาก simulator
server/dist/switchy-sim.exe -ws 127.0.0.1:8090 -clients 2 -seconds 8
# ดู log ฝั่งเซิร์ฟเวอร์: "PTT state=\"KEY (ส่ง)\" device=usb-serial:COM3"
```

## 2. Audio bridge (เฟส 2 — ต้องมี USB Soundcard)

`roip.Gateway` ในเฟสนี้เตรียมทาง UDP ให้แล้ว: รับเสียงจาก IP แล้วส่งไปที่ `roip.audioUdp`
และรับเสียงจากวิทยุกลับเข้ามาในห้อง Intercom เป็น clientNum `65520` (ค่าคงที่ `roip.RadioClientNum`)

ยังเหลือ **helper** ตัวเล็กที่คุยกับ USB Soundcard (ต้องใช้ PortAudio จึงแยกออกมา ไม่ผูกกับเซิร์ฟเวอร์ Go):

```json
"roip": { "audioUdp": "127.0.0.1:50600" }
```

สัญญาณบนลิงก์นี้ = PCM 16-bit mono (เหมือนในโปรโตคอลเสียง SWITCHY แต่ไม่มี header 16 ไบต์)

**หมายเหตุสำคัญ:** helper ต้องใช้ `codec = pcm` เท่านั้น
ถ้าไคลเอนต์ส่ง Opus เซิร์ฟเวอร์จะบันทึก log เตือนและไม่ส่งต่อให้วิทยุ (เพราะต้องถอดรหัสก่อนออก analog)

## 3. เช็กลิสต์ก่อนใช้งานจริง

- [ ] วิทยุมีขา PTT ที่สั่งได้ (หรือใช้โหมด VOX ในตัว)
- [ ] ต่อสายแล้ววัดด้วยมิเตอร์: กดปุ่ม = ขา PTT ต่อลง GND จริง
- [ ] ตั้ง `talkTailMs` ให้ท้ายคำไม่ขาด (ทดลอง 250 → 400 ms)
- [ ] ถ้าพูดพร้อมวิทยุแล้วมีสัญญาณรบกวน ให้เปิด Noise Gate ฝั่งแอป (ค่าเริ่มต้น -45 dB)
- [ ] ระวังหูฟัง: เสียงวิทยุที่เข้ามาจะถูกกระจายให้ทุกเครื่อง → ควรใช้หูฟังกันเสียงวน
